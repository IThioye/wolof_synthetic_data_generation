# Legacy material

This directory preserves superseded implementation and planning material that
helps explain the project's development but is not part of the recommended
reproduction workflow.

- `annotation_app.py` is the former Streamlit annotation interface. The current
  Flask interfaces and shared logic live at the repository root and in `src/`.
- `presentation_planning_notes.md` contains the early defence outline. The
  finished deck and jury material live in `presentation/`.

See `notebooks/README.md` for the current experimental workflow and
`docs/repository_audit.md` for the public-release boundary.
