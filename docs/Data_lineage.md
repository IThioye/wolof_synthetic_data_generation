# Data Lineage

This file tracks where each project data artifact comes from, which step generates it, which later step uses it, and whether it is current, intermediate, experimental, or stale.

> **Current benchmark:** the final retained benchmark uses Gold-only, M1, M2, M3, M4, and M6 with the TNT-style character normalizer. M5 remains documented for traceability but was excluded from the final comparison. Canonical outputs are under `results/m7_seq2seq/tnt_edit_gold_dev_v4/` and `results/tnt_edit_report_analysis/`.

## Pipeline Overview

```text
YouTube playlists
  -> youtube data scraping/all_video_links.txt
  -> data/youtube/comments_data.json
  -> data/youtube/clean_data.csv
  -> checkpoints/batch_*.json
  -> data/checkpoint_data.csv
  -> data/filtered_data.csv
  -> flask_annotation_app.py (current interface; annotation_core.py contains shared logic)
  -> data/annotations/gold_annotations.csv
  -> data/annotations/token_corrections.csv

Formal French-Wolof resources
  -> data/translation data/train-00000-of-00001.parquet
  -> data/translation data/wolof.csv
  -> data/translation data/dictionnary_translations.json
  -> data/translation data/translation_informal_wolof.csv
  -> data/translation data/combined_informal_wolof.csv
  -> data/vocabulary.txt
  -> artifacts/lexicon.pkl

Reverse / annotation support
  -> artifacts/lexicon.pkl
  -> data/vocabulary.txt
  -> data/Lexique400/Lexique4.tsv
  -> data/test_exported_data.csv
  -> data/test_exported_data_recovered.csv
```

## Annotation Interface

The current interface is the Flask application. From the project directory, run:

```powershell
python -m src.annotation.flask_annotation_app
```

Then open `http://127.0.0.1:5000`. The application resumes after source indices
already present in `data/annotations/gold_annotations.csv`, preserves append-only
history when an existing row is edited, and learns newest-first token equivalents
from `data/annotations/token_corrections.csv`. Do not run the legacy Streamlit and
Flask annotation applications simultaneously because both append to the same CSVs.

## Central Path Configuration

Python entry points and active notebooks use `config.py` as the single registry
for project, dataset, artifact, checkpoint, annotation, and scraper paths. Paths
are absolute and no longer depend on the current working directory. The default
locations can be overridden with `PFE_PROJECT_ROOT`, `PFE_DATA_DIR`, and
`PFE_ARTIFACTS_DIR`. Change the constants in that file when the planned folder
reorganization is performed instead of editing paths throughout individual files.

## Known Caveats

1. The filtered-data index bug was repaired on 2026-07-19.
   `data/filtered_data.csv` now joins the full clean dataset to checkpoint labels by original index and retains 5,498 positives with provenance columns.

2. `data/filtered_data copy.csv` appears to be a duplicate of `data/filtered_data.csv`.
   Keep only one unless the copy has manual edits.

3. The former duplicate `artifacts/Lexique4.tsv` was verified byte-identical to
   `data/Lexique400/Lexique4.tsv` and removed. `src/config.py` now registers the
   latter as the only canonical path.

4. `data/test_exported_data_recovered.csv` is not gold data.
   It is automatic output from the reverse pipeline. It can help annotation, but final benchmark rows must be manually corrected.

5. `data/gold_annotations.csv` and `data/token_corrections.csv` are planned outputs from `annotation_app.py`.
   These should become central to the real-comment-informed pipeline.

## Recommended Clean Pipeline Going Forward

1. Treat the current 201 kept annotations across five videos as the selected stopping point.
2. Recheck kept pairs against the fixed target policy and review exact or near duplicates.
3. Explicitly freeze annotation, then create video-disjoint `train`, `dev`, and locked `test` splits with `prepare_gold_splits.py`.
5. Use only gold train/development data plus non-held-out comments to design the real-comment-informed generator.
6. Keep `test` locked for final comparison of:
   - rules-only informalization
   - rules + eflomal code-switching
   - rules + CMDR code-switching
   - real-comment-informed generation
   - optional LLM-generated baseline
