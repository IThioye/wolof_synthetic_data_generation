# Final defence material

This directory contains only the final presentation and the supporting defence
notes intended for publication with the project.

- `PFE_Defence_Ibrahima_THIOYE_2026.pptx`: editable final deck.
- `PFE_Defence_Ibrahima_THIOYE_2026.pdf`: rendered deck.
- `Jury_QA_Cheatsheet.*`: extended answers to likely jury questions.
- `Defense_questions_by_slide.md`: slide-specific preparation questions.
- `PFE_Defence_Guide.md`: timing and delivery guidance.

The local `Final Presentation/` folder is intentionally ignored. It contains
design references, preview images, generation scripts, and superseded deck
versions that are useful locally but not part of the clean repository.
