# Generated artifacts

This directory stores compact, inspectable outputs produced by the generation
pipelines, especially the final M6 mappings and context templates.

Large binary models are local build products and are ignored:

- `cmdr_word2vec.model*` can be regenerated by the M3 workflow;
- CMDR alignment tables can be regenerated by M3;
- trained evaluator weights live under the ignored `checkpoints/` directory.

The exception is `lexicon.pkl`: this small, checksum-verified M2 artifact is
versioned so Eflomal does not have to be rebuilt. Its provenance and security
note are in `docs/eflomal_reproducibility.md`.

CSV and JSON artifacts that support a final reported number should remain
versioned. M5 candidates are local because M5 was excluded from the final
benchmark.
Every retained artifact should identify its producing notebook or module in
`docs/Data_lineage.md`.
